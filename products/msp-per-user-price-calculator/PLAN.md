# MSP Per-User Price Calculator

**Audience:** managed service providers (MSPs), IT support companies and freelance IT consultants who price support contracts per user.
**Problem:** Per-user prices set without the tool and labour cost behind each user can leave far less margin than intended; fixed tool costs shift the cost per user as head count changes.
**Monetization:** AdSense + pricing kit cross-sell.
**Scope:** client-side calculator, pure tested functions, 650+ word explainer with FAQ. Formulas: tool cost per user = per-user tools + fixed tools ÷ users; labour cost per user = support hours per user × loaded hourly cost; cost per user = tool + labour; price per user = cost per user ÷ (1 − margin % ÷ 100), margin as a share of price; monthly revenue = price × users; monthly profit = (price − cost) × users. Rejects 0 users and a margin of 100 or more.
**Out of scope:** industry benchmarks, typical prices, averages or ranges, target percentages, tax, saving data.
**Done when:** tests pass, page renders, LAUNCH.md ticked.
