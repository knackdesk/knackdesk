# Event Staffing Calculator

**Audience:** caterers, venues, event planners and staffing agencies quoting service staff.
**Problem:** Staff quotes forget setup, breakdown and minimum shifts, so labour is underpriced.
**Monetization:** AdSense + pricing kit cross-sell.
**Scope:** client-side calculator, pure tested functions, 650+ word explainer with FAQ. Formulas: servers = ceil(guests ÷ guests per server); hours per server = max(event + setup hours, minimum); total hours = servers × hours per server; labour cost = total hours × rate; cost per guest = labour ÷ guests.
**Out of scope:** employment law, overtime rules, scheduling, saving data.
**Done when:** tests pass, page renders, LAUNCH.md ticked.
