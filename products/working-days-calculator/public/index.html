Working Days Calculator

Count the working days between two dates, or find the date that falls a given number of working days after a start date. Weekends are skipped, and so is any holiday you list. Nothing is sent anywhere.

In one sentence: Working days are the weekdays between two dates, excluding Saturdays, Sundays and any holidays you list.

Formula: working days = calendar days in range − weekend days − listed holidays on weekdays; adding N working days counts from the day after the start date.

Why working days get counted differently

"Ten working days" sounds precise, yet two people can land on different dates. One counts the day the request arrived, the other starts tomorrow. One skips a public holiday, the other forgets it exists. In a contract, a quote or a delivery promise, that one-day gap can be the difference between on time and late.

This calculator makes the rules visible. In counting mode, both the start date and, by default, the end date are included, so Monday to Friday of the same week is five working days. Untick "Count the end date" if you want to count the days up to but not including the end. In adding mode, the start date itself is never counted: one working day after a Friday is the following Monday.

Neither convention is wrong. What matters is that everyone involved uses the same one, and that the date you promise is written down. If a client sends a brief late on a Friday, agreeing whether Friday counts as day one avoids an awkward conversation two weeks later.

Weekends and holidays

Saturdays and Sundays are always treated as non-working days. Public holidays differ by country, region and sometimes by industry, so the tool does not guess them. Paste the dates that apply to you, one per line, and they are skipped. A holiday that falls on a weekend is only counted once, as a weekend day.

If you work a different pattern, such as a four-day week or shifts that include weekends, the result will not match your calendar. Treat it as a standard Monday to Friday count and adjust from there. Company shutdown periods, such as a week off at the end of the year, can be entered as a run of individual holiday dates.

It helps to keep a short list of the holiday dates you observe for the year in a note somewhere, so you can paste the same list each time. Remember that holidays in your client's country may differ from yours. If you work across borders, a deadline might need to skip both sets of dates, or you may want to agree whose calendar applies before the work starts.

Using working days in quotes and deadlines

Quoting turnaround in working days protects you from weekends eating into the schedule, but it only works if the client reads the date the same way you do. A good habit is to give both: "ten working days, so by Friday 16 October". Writing the actual date removes any argument about what was meant.

The same idea applies to payment terms. Invoices are often due a number of calendar days after issue, but some contracts use business days. If you need to work out an invoice due date specifically, the invoice due date calculator handles both. For planning capacity, counting the working days in a month or a project window also tells you how many billable days you actually have, which is a useful check before you commit to a fixed-price deadline. Notice periods and statutory deadlines follow rules that vary by country and contract, so check the wording that applies to you; this tool only counts the days you give it.

Frequently asked questions

Does the count include the start date?

Yes, when counting between two dates. When adding working days, counting starts from the next day, which is the usual convention, but confirm it with whoever set the deadline.

Which public holidays are included?

None by default. Holidays vary by location, so add the dates that apply to you in the holidays box.

How far ahead can I add?

Up to 3,650 working days, which is well over a decade.

Is my data stored?

No. Everything runs in your browser.
